# mrahman93.github.io

Personal website for **Md Mahmudur Rahman** — Applied Scientist at Amazon.
Static HTML/CSS/JS, hosted via GitHub Pages.

## Local preview

```bash
python3 -m http.server 8000
# open http://localhost:8000
```

## Files

- `index.html` — single-page site
- `styles.css` — dark gradient theme
- `script.js` — scroll reveal, active nav, mobile toggle
- `assets/resume.pdf` — downloadable CV
- `assets/profile.jpg` — hero portrait *(add your photo here; falls back to "MR" mark if missing)*
- `.nojekyll` — disables Jekyll processing on Pages

## Deploy

This repo is `mrahman93/mrahman93.github.io`, so Pages serves the root branch
at `https://mrahman93.github.io`.
